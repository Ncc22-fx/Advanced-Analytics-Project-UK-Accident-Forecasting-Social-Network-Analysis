# Advanced-Analytics-Project-UK-Accident-Forecasting-SQL_DB-Social-Network-Analysis

## Project Overview
This project combines two independent analytical tasks within a single Jupyter Notebook to demonstrate the application of advanced data science techniques across different problem domains.

The notebook includes:

Time Series Forecasting: Predicting future UK road accident trends using historical accident database
Social Network Analysis: Analyzing relationship structures within a separate network dataset to identify influential nodes and interaction patterns

The project showcases versatility in working with multiple datasets and applying different analytical techniques within one workflow.

Module 1: UK Road Accident Time Series Forecasting
Objective

To analyze historical UK road accident trends and forecast future accident occurrences.

### Dataset
Official road accident dataset from UK Department for Transport STATS19 database.
Features
Accident dates
Casualties
Vehicle types
Weather conditions

### Data cleaning
